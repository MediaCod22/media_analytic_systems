# Data reported in manuscript version 5

This directory records the aggregate values printed in version 5 of the manuscript prepared for *Medi@lmanah*. The files were transcribed from the manuscript so that its tables can be checked mechanically against the repository.

## Included files

- data/derived/manuscript_v5_corpus_summary.csv — PRISMA-style corpus counts, system mentions, and explicit DSS connections.
- data/derived/manuscript_v5_mode_distribution.csv — distribution of 327 publications across five mutually exclusive analytical modes.
- data/derived/manuscript_v5_tools_summary.csv — reported summary of 51 tools: 14 Russian, 30 international, and 7 Chinese.
- data/derived/manuscript_v5_coding_reliability.csv — reliability values reported for the 33-publication subsample.
- tables/table_4_manuscript_v5_representative_systems.csv — representative systems and analytical products printed in the manuscript.

## Provenance and evidentiary status

These files contain **manuscript-reported aggregate data**. They are not a substitute for the publication-level coding matrix. The repository does not currently expose 327 bibliographic records with source URLs/DOIs and their individual coding decisions. Consequently, these aggregate files support consistency checks between the manuscript and repository, but do not by themselves make the systematic mapping independently reproducible.

The five-mode counts are recorded exactly as printed in manuscript version 5. They must be verified against the source-level coding matrix before the article is submitted or described as an empirically reproducible result.

## Known reconciliation item

The manuscript reports 51 tools (14/30/7), while the earlier full registry in this repository contains 52 positions and uses a different contour split. No registry row has been deleted automatically: identifying the excluded or reclassified tool requires a source-level reconciliation decision.
