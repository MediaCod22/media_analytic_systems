# GitHub release notes draft

## v1.1.0-mediaalmanach-revision

Релиз содержит открытый исследовательский пакет к рукописи «Медиааналитика и поддержка принятия решений в научном дискурсе: систематическое картирование российского, англоязычного и китайского корпусов публикаций».

### Изменено в версии v1.1.0

- Реестр приведён к финальной версии статьи: **50 инструментов**.
- Распределение по корпусам: **13 российских, 30 международных, 7 китайских**.
- Из реестра удалены позиции, не являющиеся самостоятельными аналитическими инструментами.
- Названия инструментов нормализованы в соответствии с таблицей 3 статьи.
- Описание выборки приведено к единой версии: 804 → 477 исключено → 327 включено.
- Удалены ссылки на предполагаемую публикацию рукописи в стороннем журнале.
- Пакет приведён к единой дате версии: **2026-08-06**.
- Уточнено методологическое различие между тематическим режимом и бинарным кодированием DSS-связи.

### Содержимое

- адаптированный PRISMA-протокол;
- поисковая стратегия для Google Scholar, eLibrary/РИНЦ и CNKI;
- кодировочная книга;
- агрегированные таблицы по выборке, DSS-связи и типологии режимов;
- финальный реестр инструментов;
- обезличенный фрагмент кодировочной матрицы;
- скрипты валидации таблиц и расчёта Cohen’s Kappa;
- метаданные набора данных.

### Основные числа

- 804 первично найденных записи;
- 477 записей исключено при скрининге;
- 327 публикаций в итоговой выборке;
- 112 публикаций Google Scholar, 95 РИНЦ, 120 CNKI;
- 50 инструментов: 13 / 30 / 7;
- DSS-связь: Google Scholar — 15 (≈13%), РИНЦ — 8 (≈8%), CNKI — 42 (35%);
- Cohen’s Kappa: 0,91 (DSS-связь), 0,84 (тематическая классификация).

### Границы интерпретации

Пакет описывает сформированные корпуса научных публикаций. Показатели не являются рыночными долями, оценками качества платформ или характеристиками национальных уровней технологического развития.
