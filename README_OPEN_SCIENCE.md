# Open Science package: медиааналитика и поддержка принятия решений

> **Версия пакета:** v1.1.0
> **Дата версии:** 2026-08-06

## Назначение репозитория

Этот пакет сопровождает статью «Медиааналитика и поддержка принятия решений в научном дискурсе: систематическое картирование российского, англоязычного и китайского корпусов публикаций» и обеспечивает воспроизводимое описание дизайна исследования, адаптированного протокола PRISMA 2020, структуры данных, кодировочной схемы и производных таблиц.

Исследование выполнено как описательное систематическое картирование научного дискурса. Сравниваются не национальные рынки и не фактическая эффективность платформ, а три сформированных корпуса публикаций: российский (eLibrary/РИНЦ), международный англоязычный (Google Scholar) и китайский (CNKI).

## Исследовательская рамка

**Объект:** научные публикации о медиааналитике, медиамониторинге, медиаметрии, OSINT, public opinion monitoring / 舆情监测 и связи медиаданных с поддержкой принятия решений.

**Предмет:** способы концептуализации медиаданных, аналитических продуктов и DSS-связи в научных публикациях.

**Исследовательский вопрос:** как в российском, международном и китайском корпусах представлена связь между медиааналитикой и поддержкой принятия решений?

**Задачи:**

1. определить упоминаемость конкретных инструментов медиааналитики;
2. установить частоту явной DSS-связи;
3. распределить публикации по пяти режимам работы с медиаданными.

## Ключевые результаты

| Корпус | Публикации с упоминанием систем | Публикации с DSS-связью |
|---|---:|---:|
| Google Scholar | 18 (≈16%) | 15 (≈13%) |
| eLibrary/РИНЦ | 31 (≈33%) | 8 (≈8%) |
| CNKI | 54 (45%) | 42 (35%) |

Различия относятся к сформированным корпусам научных публикаций и не интерпретируются как доказательство технологического превосходства, рыночной зрелости или фактического уровня внедрения медиааналитики в конкретной стране.

## Типология режимов аналитической работы с медиаданными

| Режим | Российский пример | Международный пример | Китайский пример | Аналитический продукт |
|---|---|---|---|---|
| Медиаизмерения | Mediascope | Nielsen | — | Охват, контакт |
| Мониторинг медиапространства | Brand Analytics, СКАН | Factiva, LexisNexis | Юйцин-платформы | Мониторинг, нарративы |
| OSINT и дата-журналистика | OSINT + BA/СКАН | GDELT + OSINT | Юйцин-анализ | Реконструкция событий |
| Поддержка решений и предиктивная аналитика | «Талисман», риск-аналитика | Signal AI, Dataminr | Sina Yuqing, Wisers | Сценарии, рекомендации |
| ИИ-нативный режим | Исследовательские LLM | NetBase Quid | Midu | Ответ на открытый запрос |

## Как использовать

1. Поместить содержимое пакета в корень репозитория `MediaCod22/media_analytic_systems`.
2. Сохранить исходные выгрузки из Google Scholar, eLibrary/РИНЦ и CNKI локально либо описать причины, по которым они не публикуются полностью.
3. Проверить производные таблицы командой:

```bash
python scripts/validate_tables.py
```

4. Проверить расчёт согласованности кодирования командой:

```bash
python scripts/calculate_kappa.py
```

5. Создать GitHub Release `v1.1.0-mediaalmanach-revision` от 2026-08-06.

## Ограничение опубликованных данных

Итоговые показатели рассчитаны по полной выборке из 327 публикаций. Файл `data/processed/master_publications_coded.csv` содержит обезличенный фрагмент кодировочной матрицы (100 записей) для документирования схемы кодирования; он не является полной копией аналитического корпуса. Полные тексты и защищённые выгрузки баз данных не распространяются.
